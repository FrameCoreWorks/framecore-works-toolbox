## Setup after install

A local site; Lighthouse when you run audits.

## What works where

Chat, Cowork and Claude Code.

## Use

Ask to audit or speed up a page, or `/web-quality-skills:`.

Watch out: no special setup.

## Full removal

Remove it in Customize > Plugins, or run `claude plugin uninstall web-quality-skills@framecore-works-toolbox`. Delete files it created in your projects if you no longer need them.
