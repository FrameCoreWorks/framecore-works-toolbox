## Use

In a finished project, ask for a launch video or `/brag:brag`.

Watch out: overlaps with motion-designer; pick one per job.

## Full removal

Remove it in Customize > Plugins, or run `claude plugin uninstall brag@framecore-works-toolbox`. Delete files it created in your projects if you no longer need them.
