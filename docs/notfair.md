## Install

See [install.md](install.md). Plugin id: `notfair@framecore-works-toolbox`.

## Setup after install

A NotFair account for the MCP; optional Google credentials.

## What works where

Chat (remote MCP), Cowork and Claude Code.

## Use

Connect NotFair, then ask for SEO or ads analysis.

Watch out: its MCP sends your requests and ad data to notfair.co.

## Full removal

Remove it in Customize > Plugins, or run `claude plugin uninstall notfair@framecore-works-toolbox`. Delete files it created in your projects if you no longer need them.
