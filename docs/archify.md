## Install

See [install.md](install.md). Plugin id: `archify@framecore-works-toolbox`.

## Setup after install

Node for its scripts; a browser to view the HTML.

## What works where

Chat, Cowork and Claude Code.

## Use

Ask for a diagram of a system or plan, or `/archify:archify`.

Watch out: runs a small update check when used.

## Full removal

Remove it in Customize > Plugins, or run `claude plugin uninstall archify@framecore-works-toolbox`. Delete files it created in your projects if you no longer need them.
