## Install

See [install.md](install.md). Plugin id: `nateherk-design@framecore-works-toolbox`.

## Setup after install

A web stack in your project; optional kie.ai key.

## What works where

Chat, Cowork and Claude Code.

## Use

Ask for a scroll-driven landing page, or `/nateherk-design:scroll-craft`.

Watch out: images go to kie.ai only with `KIE_AI_API_KEY`.

## Full removal

Remove it in Customize > Plugins, or run `claude plugin uninstall nateherk-design@framecore-works-toolbox`. Delete files it created in your projects if you no longer need them.
