## Install

See [install.md](install.md). Plugin id: `sepia@framecore-works-toolbox`.

## Setup after install

None.

## What works where

Chat, Cowork and Claude Code.

## Use

Ask to de-AI a text, or `/sepia:sepia`.

Watch out: overlaps with Studio's Humanizer.

## Full removal

Remove it in Customize > Plugins, or run `claude plugin uninstall sepia@framecore-works-toolbox`. Delete files it created in your projects if you no longer need them.
